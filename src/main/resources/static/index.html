Proyectos

  • Sistema de Gestión Académica

    Proyecto desarrollado en Java para administrar estudiantes, cursos e inscripciones.
    Se utilizaron diferentes estructuras de datos para resolber las necesidades del sistema,
    incluyendo árboles binarios, árboles AVL, listas, colas, pilas y arreglos dinámicos.

    El proyecto permitió aplicar conceptos de programación orientada a objetos, estructuras de datos
    y organización de la lógica de un sistema.

  • Servidor de Chat Cliente-Servidor

    Proyecto desarrollado en Python utilizando comunicación mediante TCP y UDP.
    El sistema permite la conexión de múltiples clientes, manejo de nombres de usuario, asignación de colores,
    lista de usuarios y envío de mensajes. También se trabajó con validaciones y comunicación entre servidor y clientes.
